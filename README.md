# Road Accident Severity Prediction

A Machine Learning-based system for predicting road accident severity using accident-related transportation data.

## Project Overview

This project analyzes road accident data and uses Machine Learning to classify accident severity into different categories.

## Objectives

- Analyze road accident patterns
- Identify important factors affecting accident severity
- Build a Machine Learning classification model
- Predict accident severity based on accident conditions

## Dataset

The dataset contains 10,000 accident records with features such as:

- State
- District
- Year
- Month
- Hour
- Weather Condition
- Road Type
- Vehicle Type
- Cause of Accident
- Accident Severity

## Machine Learning

The project uses a **Random Forest Classifier** for accident severity classification.
